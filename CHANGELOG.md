All notable changes to this project are documented in this file. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-07-31

### Added
- Initial public release: onboarding, permission education, device discovery (NSD + UDP fallback), encrypted QR/PIN pairing, trusted device dashboard (battery/storage/RAM/uptime), ring/vibrate/flashlight find mode, background monitoring service with auto-reconnect, Settings/About/Privacy/Licenses screens, Material 3 dark/light UI.
